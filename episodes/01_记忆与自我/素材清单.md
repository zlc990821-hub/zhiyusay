# 第 01 期 素材清单

原则：现成的真实素材优先，找不到再用代码画。风险指在抖音被判侵权的风险：低＝公有领域或免费商用授权；中＝署名授权或来源授权不完全清楚；高＝电视台、影视公司的版权内容。用不用由用户决定。

素材文件不入 Git 仓库（太大），下载位置：`episodes/01_记忆与自我/素材/`。

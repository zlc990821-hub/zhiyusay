# 我的人生系统 · 档案

这里是我的人生系统档案，由 `life-system` 技能读取和维护（技能说明见 `../skills/life-system/SKILL.md`）。

## 怎么用

- **遇到任何事**：对 Claude 说“过一下系统：……”。它会读这里的档案，按“归位、对表、照心、算账、定动作”五步出一张决策卡，经我同意后追加到《决策日志》。
- **每晚**：在 `每日两行/` 里写两行。
- **每周日晚**：说“周复盘”，按 `复盘/` 里的模板做。

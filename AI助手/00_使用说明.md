# 知予 AI 助手 · 搭建与使用说明

## 一、搭建（约 5 分钟，只做一次）

1. 电脑浏览器打开 claude.ai，左侧点 **Projects → Create Project**
2. 项目名填：`知予运营助手`
3. 点 **Set project instructions（项目指令）**，把 `01_项目指令（粘贴到Project Instructions）.md` 的**全部内容**复制进去，保存
4. 在 **Project knowledge（项目知识库）** 上传这 4 个文件：
   - `闲鱼文案_v2.md`
   - `服务框架.md`
   - `项目方案_v1.md`
   - `AI助手/02_朋友圈素材库.md`
5. 完成。以后在手机 App 或网页里进入这个 Project，新建对话就能用。

> 修改了价格、服务时间或新增服务以后，记得重新上传对应的文件，助手才会知道。

## 二、怎么用（直接复制下面的格式）

### 写朋友圈
```
【朋友圈】第3天，写3条
```
```
【朋友圈】今天下午去西湖边喝了茶，下雨，帮我写一条日常
```
```
【朋友圈】写一周的，第11–17天
```
```
【朋友圈】明天是冬至，写一条节气科普
```

### 回复客户
```
【回复】闲鱼售前
客户：在吗，倾听是真人吗？晚上12点以后还可以吗
```
```
【回复】售后第4天跟进
上次聊的是：她和男朋友异地冷战，打算周末见面谈
```
```
【回复】客户说：聊了5分钟感觉不太对，能退吗
```

### 生成小结
```
【小结】情感咨询
要点：女生，24岁，恋爱2年，异地。男友最近回消息慢，
她怀疑对方变心，但没证据。她最在意的是"被放在心上"。
讨论了两个选择：A 直接沟通自己的感受，B 先观察两周。她倾向A。
```
```
【小结】简历诊断
岗位：新媒体运营，应届。问题：经历只写职责没写结果；
自我评价太空泛；排版两页太长。优点：有一段实习数据不错（涨粉5000）。
```

## 三、使用小贴士

- 一个对话只做一类事，比如今天写朋友圈就开一个对话，回复客户另开一个，效果更稳定
- 不满意就直接说"更口语一点""短一点""换个开头"
- 贴客户消息前，删掉对方的真实姓名、手机号等隐私信息
- 助手写的案例、反馈类内容只能基于真实发生、对方同意的事情

# 第二个助手：咨询副驾驶（服务过程中实时用）

## 搭建
1. claude.ai 里新建一个 Project，名字填：`知予咨询副驾驶`
2. 把 `03_咨询副驾驶指令（单独建一个Project）.md` 的全部内容粘贴到 Instructions
3. 知识库上传 `服务框架.md`
4. 跟"运营助手"分开建，是为了让它专心做咨询判断，回复更快更准

## 服务中怎么用（手机上开着，边聊边贴）

**最简单的用法：**
```
客户：他已经三天没回我消息了，我是不是哪里做错了
```

**附上背景和你自己的想法（效果更好）：**
```
【情感】
背景：恋爱2年，异地，最近对方冷淡
客户：他已经三天没回我消息了，我是不是哪里做错了
我想：跟她说可能对方只是忙
```

**你会收到：**
- 🚦 风险等级（绿 / 黄 / 红）
- 🔍 客户此刻的情绪和真正的需要
- 💬 A / B / C 三种专业回复，以及每种用了什么技术、为什么这样回
- 🚫 这时候别说的话
- 🧭 接下来的方向
- 📝 对你自己想法的点评（如果你写了"我想"）

## 服务后
```
【复盘】
（粘贴整段对话，去掉客户的隐私信息）
```
会告诉你哪里做得好、哪里可以改进，以及这次值得学的一个技术。

## 平时学习
```
【学】客户一直哭，我该说什么
【学】情感反映
【学】怎么问对方有没有想过自杀
```

## 重要提醒
- 看到 🔴 时，先照着危机处理步骤做，别的都放一边
- 贴给 AI 的内容先去掉客户的真实姓名、电话、单位等可识别信息
- AI 给的是参考，你对客户的直觉同样重要。觉得哪句不像你会说的，就按你的方式改

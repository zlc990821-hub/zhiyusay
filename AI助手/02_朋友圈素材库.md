# 知予 · 朋友圈素材库

（给 AI 助手做参考用：人设细节、选题池、风格样例）

## 微信资料
- 昵称：紫知予说
- 签名：陪你把话说完，也陪你看看来路和去处
- 头像：真人侧脸或手部 + 茶或书，暖色调；不要用八卦图、太极这类符号

## 可用的人设素材（都是真实经历）
- 做HR时：跟很多人谈过入职、转正、离职；在离职面谈中听过很多委屈
- 跑过8个省市的高校做校招，见过很多应届生的迷茫
- 做过门店负责人，带过导购团队，理解一线打工人的累
- 做过心理学、传统文化方向的内容账号
- 日常：喝茶（老白茶等）、看书、夜里工作到很晚

## 选题池

### 生活日常（30%）
喝茶 / 看书摘句 / 下雨天 / 深夜还在回消息 / 做饭 / 散步看到的东西 / 整理房间 / 季节变化

### 情绪 / 关系感悟（25%）
敏感不是错 / 内耗 / 讨好型人格 / 分手后的自我修复 / 异地 / 冷战 / 不被理解 / 原生家庭 / 一个人的夜晚 / 做HR时听到的离职故事（匿名、去细节）/ 应届生的迷茫 / 想辞职的人

### 命理文化科普（20%）
二十四节气（按当天日期）/ 五行性格 / 天干地支小知识 / 古籍摘句（《滴天髓》《穷通宝鉴》等）/ "命理是镜子不是预言" / 本命年的说法 / 流年是什么意思
**原则：** 讲知识、讲自我认识，不讲吉凶祸福，不吓人。

### 案例 / 反馈（15%）
只用真实且已获同意的案例；去掉可识别信息；结尾标注"已获本人同意分享"

### 服务 / 档期（10%）
本周空位 / 新服务说明 / 服务边界说明（"我不卖转运物品，不做化解"）

## 风格样例

> 今天泡的是老白茶，第三泡最好喝。
> 有时候人也是这样，前两轮都在试探，第三轮才肯说真话。

> 这周听了好几个人说"我是不是太敏感了"。
> 其实敏感不是错，只是你接收到的东西比别人多。
> 累了就先把天线收一收，没关系的。

> 做HR的时候，离职面谈听到最多的一句话是：
> "其实我不是不能吃苦，是觉得委屈。"
> 很多时候让人撑不下去的，不是累，是不被看见。

> 今天立冬。
> 古人讲"冬藏"，这是一年里最适合往回收的时候。
> 不必逼自己年底前完成所有目标，养好精神，本身就是在做事。

> 最近在重读《滴天髓》。
> 小时候觉得命理是"算准"，现在越来越觉得它更像一面镜子：
> 帮人看清自己是什么样的人、在什么样的时间里。

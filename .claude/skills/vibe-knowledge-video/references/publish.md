# 验收与发布

## 1. 自动检查（engine/qa.py）

规格 1920×1080 30fps h264 · 有 AAC 音轨 · 时长 60–300s · 深色帧 > 90% · 最长静止 ≤ 4s · 响度 −16…−12 LUFS · 峰值 ≤ −0.5 dBTP

## 2. 人工检查（每条都要过）

- [ ] 抽 16 帧拼图（见下方命令），逐张看：无文字越界、无字压字、无主视觉压字幕带
- [ ] 每条字幕 ≤ 20 字，中英都在，英文无拼写错误
- [ ] 每句字幕里的动词，画面上同时在发生
- [ ] 静音看一遍也能看懂；只读字幕也能读通
- [ ] 每个数字、年份、人名都在 `script.md` 事实表里有出处
- [ ] 示意图/示意数据已标注"示意"
- [ ] 结尾有声明卡 + 参考文献 + 互动问题
- [ ] 无任何原片素材、原片文案、第三方配乐

```bash
cd projects/<slug>/out && mkdir -p chk && for t in 5 12 20 30 40 50 60 70 80 90 100 110 115 120 125 128; do ffmpeg -v error -y -ss $t -i final.mp4 -frames:v 1 chk/$(printf %06.1f $t).png; done && ffmpeg -v error -y -pattern_type glob -i 'chk/*.png' -vf scale=480:-1,tile=4x4:padding=4 -frames:v 1 chk.jpg
```

## 3. 抖音发布

- **标题**：`Vibe知识大赏 |《片名》` + 一句钩子（含数字更好）
- **正文**：2–3 句，含一个具体年份、一个人名、一个反直觉结论
- **话题**：`#Vibe知识大赏` + 3–4 个主题词（如 `#数学 #冷知识 #科普`）
- **封面**：16:9，用片中最强的一帧（通常是钩子揭晓帧或金句帧），底部 10% 不放关键字
- **置顶评论**：参考文献 + "本片动画由代码生成，无实拍素材"
- **互动**：结尾问题和置顶评论呼应，引导评论区作答

活动规则（截止日期、流量扶持）以抖音 App 内 `#Vibe知识大赏` 话题页为准。

# 叙事与文案

## 1. 选题公式

**硬知识 × 能画出来 × 反直觉 × 和"你"有关**

- 必须有一个**反直觉结论**作记忆锚（"1 占三成而不是 11%"、"多修一条路反而更堵"）。
- 必须有**可画的机制**：能用柱子、曲线、格子、尺子、卡片、粒子演示的。纯思辨题要找"寓言式"形象（骆驼/狮子/孩子）。
- 必须有**具体年份 + 人名 + 出处**开路，建立可信度。
- 最后**落到观众生活**：相亲、堵车、听歌、工资条、抽卡、排队。

## 2. 六段式（以 130s 为基准）

| 段 | 时长 | 功能 | 写法 |
|---|---|---|---|
| ① 冷开场钩子 | 0–12s | 抛出反直觉问题 | 2–4 句短字幕；先给直觉答案，再一句话打碎它 |
| — 标题卡 | 12–18s | 《片名》+ 一句副标题 + 英文 | 先问题后标题 |
| ② 历史锚点 | 18–50s | 可信度 | 顶标签"年份·地点·事件"；文献复原 + 人物铭牌；1–2 个历史节点 |
| ③ 机制模拟 | 50–90s | 核心推演（占 30–45%） | 先立规则卡，再 3–5 步推演，每步：动作 → 注释 → 字幕 |
| ④ 反直觉转折 | 90–104s | 翻转/应用 | 并排对比，或"所以……反而……" |
| ⑤ 现实落点 | 104–116s | 回到生活 + 金句 | 适用/不适用、诺奖、现实系统；金句 ≤ 16 字 |
| ⑥ 声明与收尾 | 116–130s | 合规 + 互动 | 声明卡 → 参考文献 → 互动问题 + 出品 |

## 3. 字幕写法

- 每句 ≤ 20 个汉字，显示 2.5–3.6s（约 6–8 字/秒）；句间隔 0.2–0.3s。
- 关键词用「」；数字用阿拉伯数字，单位前空格（"20229 个"）。
- 英文副句是**意译**不是直译，短、有节奏，像片尾字幕。
- 先现象后概念：先让观众看到"脏页"，再说"1 开头的数被查得最多"。
- 提问句、结论句、引文出现时，画面不要再塞新元素——让它停一下。

## 4. 钩子句式

1. **直觉 → 打碎**："1 到 9，直觉告诉你：机会均等 / 可在真实世界里，「1」占了将近三成"
2. **A，却 B？**："多修了一条路，所有人反而更慢？"
3. **同样的 __，只改一件事**："同样的 8 个人，同样的心意 / 只改一件事：谁先开口"
4. **如果 X，你会 Y 吗？**："如果只能见 10 个人，你会在第几个停下？"
5. **随手可验证**："随手翻开一本账，数字的第一位是几？"

## 5. 金句

≤ 16 字，可转发，带一点温度。
- 自然生长的数，偏爱从 1 开始
- 错过，不等于不够好
- 等待本身，就是快乐
- 散场后的空，是自由

# 风格 DNA

综合多个开源拆解（见 `docs/research.md`）与本仓库样片实测后的规范。数字是"默认值"，有理由可以偏离，但要整片一致。

## 1. 成片规格

| 项 | 值 |
|---|---|
| 画幅 | 1920×1080 横屏，30fps，H.264 yuv420p（tv range） |
| 时长 | 100–170s，甜区 120–145s |
| 音频 | AAC 44.1kHz 192k；响度 −14 LUFS，真峰 ≤ −1 dBTP |
| 声音 | 无人声。纯器乐 BGM（76–78 BPM，小调）+ 事件音效 |

## 2. 五区布局（y 以 1080 为准）

| 区 | 位置 | 内容 | 引擎 |
|---|---|---|---|
| 水印 | 左上 (56, 58) | `@账号`，26px，半透明，全片固定 | `watermark` |
| 顶标签 | y=92 居中 | `年份 · 地点 · 事件` 或 `机制 · xxx`，金色，字距 6 | `V.label` |
| 主视觉 | y=160–720 | 主角物、图表、卡片、文献 | `V.scene` |
| 注释带 | y≈768 | 手写体橙色小字，对画面即时解说 | `V.note` |
| 字幕带 | y=935 / 988 | 中文 46px 粗体白 / 英文 27px Garamond 斜体灰 | `V.sub` |

## 4. 字体（均为 SIL OFL 开源）

| 族 | 用途 |
|---|---|
| Noto Sans SC 500/700/900 (`sans`) | 字幕、标签、数字标签 |
| Noto Serif SC 700/900 (`serif`) | 片名、金句、大数字、人物名 |
| EB Garamond 斜体 (`en`) | 英文副句、文献标题、参考文献 |
| LXGW WenKai (`hand`) | 注释带、手写批注 |

字号层级：爆点 120–160 / 片名 120 / 金句 84 / 主标题 50–64 / 字幕 46 / 标签 26–34 / 注释 24–30 / 底注 18–22。

## 5. 动效

- **缓动**：一律 `E.out` / `E.inOut` / `E.outBack` / `E.spring`，禁止匀速（计数器除外）。
- **进场**：淡入 + 上移 8–14px；卡片带 `outBack` 微弹；线条用 `g.path(pts, k)` 自绘。
- **强调**：变金 + 发光（glow 14–30）+ 1.05× 放大；数字滚动计数。
- **转场**：场景交叠 0.4–0.6s 交叉淡化；优先"内容生长式"（数字飞成柱子、柱子变形、卡片缩成角标）；禁止黑场。
- **呼吸**：背景光尘 + 漂移光晕常驻；静态卡片用 `V.push(g, lt, 0.004–0.01)` 慢推镜，`g.float()` ≤ 3px 漂浮。
- **最长静止 ≤ 4s**（qa.py 检查）。
- **节拍**：77 BPM → 1 拍 0.78s、1 小节 3.12s。大段落切换尽量落在小节头（`V.bar` 的整数倍）。

## 7. 禁用清单

霓虹、玻璃拟态、HUD 网格、故障闪烁、打字机音效、emoji、真实照片、3D、白底、满屏文字、一屏多个金色焦点、弹跳滥用（`outBack` 只给卡片进场）。

# 电子王阳明 · 阳明心学行动指南

> 把《传习录》和《王文成公全书》蒸馏成一个 AI 技能（Skill）。遇到任何决策、做事、内容创作或内耗时，它会站在王阳明的角度帮你辨病根、开功夫，并把功夫落到你手上那件具体的事上。

王阳明说，“人须在事上磨，方立得住”。这个项目不打算再造一本心学讲义，它想做的是一个**随叫随到的讲学朋友**：

- **辨病**：把“我很焦虑”“道理都懂做不到”“一直刷数据”这些症状，翻译成阳明说的病根（好名、欲速、助长、逐物、悬空、乡愿……）；
- **开方**：从 20 味“功夫”里挑最对症的一两味（立志、立诚、事上磨练、主一之敬、省察克治、克去三心、此心不动……）；
- **落到事上**：给出做之前、做之中、做之后的可执行清单；
- **交还良知**：最后留一个只有你自己能回答的问题。阳明说，“尔那一点良知，是尔自家底准则”。

**每一句原文引用都可核查。**技能内置 52 篇王阳明原著全文（繁简两版）、一个检索脚本，以及一个引文校验脚本。网上很多“王阳明语录”是伪托的，这里引的每一句都能在原文里逐字查到。

## 先看一个例子

**问：我在做短视频，应该用什么样的功夫去做？**

> **一句话**：短视频便是你的“簿书讼狱”，不须离了它别寻功夫。病不在短视频，在人自累于得失。做的时候一心在“诚”上，不在“火”上，这便是敬。
>
> 阳明讲学书：“吾始学书，对模古帖，止得字形……既后读明道先生书曰：吾作字甚敬，非是要字好，只此是学。”换成做视频，就是**非是要视频火，只此是学**。……

完整回答（四味功夫、四关清单、“不可因……而……”卡片、每周省察表、验处）见 [`examples/001-短视频该用什么功夫.md`](examples/001-短视频该用什么功夫.md)。

更多示例：

- [`examples/002-被骂贩卖焦虑想回怼怎么办.md`](examples/002-被骂贩卖焦虑想回怼怎么办.md)：技能实测记录。一个全新的 Claude 实例自动调用本技能，自己从语料里检索出《与陆原静》《答友人》等参考文件之外的原文。

### 怎么问

直接说你的事就行，不必说“用王阳明的角度”（当然说了更好）：

- “我要不要辞职全职做自媒体？用阳明心学帮我想想。”
- “每次发完视频都忍不住一直刷数据，怎么办？”
- “团队里有个人总不服我，我该怎么跟他说？”
- “道理我都懂，就是拖延，知行合一到底怎么做？”
- “练毛笔字为什么说是练‘敬’？”
- “‘满街都是圣人’是王阳明说的吗？”（它会帮你辨伪）

## 附：人生系统（`life-system` 技能）

一个“个人操作系统”技能，与电子王阳明配合使用。任何事情都可以丢给它“过一遍系统”：

- **结构**：六板块，即健康、自我成长、社会关系、事业与目标、兴趣与热爱、心态调整；
- **判断**：王阳明的致良知，做让自己心安的事，并分清怕、愧、比三种不安；
- **战略**：纳瓦尔的原则，即专长、杠杆、担责、长期复利；
- **流程**：归位、对表、照心、算账、定动作五步，输出一张决策卡；
- **节奏**：日、周、月、季、年复盘模板，启动期只做三件事。

个人档案（宪法、目标、决策日志）请放在**私密**位置，技能目录里只有空白模板。详见 [`skills/life-system/SKILL.md`](skills/life-system/SKILL.md)。

### 自己重建语料

```bash
pip install opencc
python3 tools/fetch_wikisource.py raw/ tools/titles.txt     # 限速下载，约 15 分钟
python3 tools/build_corpus.py raw/ skills/wang-yangming/corpus
python3 tools/verify_quotes.py                               # 校验所有引文
```

### 检索原文

```bash
cd skills/wang-yangming
python3 scripts/search.py 事上磨               # 关键词（忽略标点差异）
python3 scripts/search.py 好名 务实             # 多词同时命中
python3 scripts/search.py --entry 241           # 《传习录》第 241 条全文
python3 scripts/search.py 作字甚敬 --file siku  # 只搜年谱等四库本
python3 scripts/search.py 學書 --hant           # 繁体原文
```

## 设计原则

1. **因病而药**：先诊断，后开方，一次只开最对症的一两味。
2. **不离事物**：功夫必须落到你的具体事务上，不悬空讲心性。
3. **有个头脑**：不排斥方法、数据和结果（“如何不讲求？只是有个头脑”），只是不让它们做主。
4. **引文可核查**：先检索，后引用；检索不到的句子不当原文。
5. **判断权归你**：它是镜子和朋友，不替你做决定。

# 天元纪元 · 分镜与转场规范 v1.0

更新：2026-11-12 ｜ 适用：风格 C（粒子 + 金色线描）及之后各期

## 一、核心原则：不要 PPT
**场景之间不允许“上一个淡出、下一个淡入”的平切。** 每一次转场，观众的视线都要被一个“看得见的东西”从上一个画面带到下一个画面。

## 二、五种允许的转场（按优先级）
| 方式 | 做法 | 例子 |
| :-- | :-- | :-- |
| 1. 变形（Morph） | 同一批粒子从 A 形状流动重组为 B 形状 | 人 → 单细胞 → 鱼 → …；恐龙 → 灰烬 → 小哺乳动物 |
| 2. 光线引导（Light as thread） | 一个光点/光束贯穿两个场景，眼睛跟着它走 | 卵子的光升起 → 成为标题的光 → 成为坠落的小行星 |
| 3. 连续镜头运动 | 推、拉、摇、移，粒子和线描在同一个“世界坐标”里一起运动 | 推进卵子；从地面拉远到整个地球 |
| 4. 匹配剪辑（Match cut） | 形状/位置/颜色在两个画面里对齐 | 撞击点 → 地球上同一个撞击点 |
| 5. 缩入/缩出到一点 | 画面缩成一个点，再从该点展开下一个画面 | 史前场景缩进地球上的尤卡坦 |

只有在叙事真正“停顿/换章”时才允许落黑，并且落黑前后要有声音或光点衔接。

## 三、画面元素的归属
- **世界元素**（粒子、线描剪影、地平线、卵子、图钉）：放在同一个世界坐标里，随镜头一起推拉摇移。
- **界面元素**（字幕、层级色标、大数字字卡、时间轴、环形图）：固定在屏幕上，像“仪表盘”，可以淡入淡出。
- 文字尽量“长”在物体上：从光点浮出、跟随引线指向物体，而不是凭空出现在屏幕中间。

## 四、每个镜头在分镜表里必须写清
1. 画面内容（主体是什么、在哪里）
2. 入场方式：从上一个镜头的哪个元素接过来
3. 出场方式：交给下一个镜头的哪个元素
4. 镜头运动（起止位置、缩放）
5. 对应的旁白句与时间点、音效

## 五、EP01 开场（0–46.5 秒）转场设计
| 时间 | 镜头 | 入场（接自） | 出场（交给） | 镜头运动 |
| :-- | :-- | :-- | :-- | :-- |
| 0:00 | 光点 → 人的剪影 | 黑场中一个光点 | 人的粒子 | 静止 |
| 0:09 | 人 → 单细胞 → … → 你 | 变形：人散开重组为单细胞；时间轴光点从“今天”甩回“38 亿年前” | 变形逐级传递 | 静止，时间轴推进 |
| 0:15 | 你 → 精子群 | 变形：人的粒子向左流散成一大群游动的光点 | 群体游向卵子 | 微拉远 |
| 0:19 | 唯一抵达 → 卵子发光 | 金色光点进入卵子 | 镜头推进卵子的光 | 推进 |
| 0:21 | 光升起 → 标题 | 卵子的光收成一个光点并上升，镜头跟着向上 | 光点悬在标题上方 | 跟随上摇 |
| 0:27 | 光点 → 小行星；镜头下摇出现史前地平线 | 标题的光点（同一个光） | 光点留在右上方的天空，成为小行星；其余粒子落下聚成恐龙 | 下摇 + 左移 |
| 0:30 | 撞击 → 恐龙化为灰烬 → 小哺乳动物 | 小行星沿轨迹坠落 | 灰烬重组 | 冲击微震，随后推进到小哺乳动物 |
| 0:37 | 地面 → 整个地球 | 史前场景缩小、收进地球上的撞击点 | 地球 + 13% + 图钉 | 拉远 |

# 天元纪元｜知识与思想探索视频制作总纲 v1.0

更新：2026-10-21  ｜ 状态：双方讨论确认的工作规范；尚未完成模板工程和第一部成片验证

## 一、项目目标
制作具有科学知识依据、思想深度、视听美感和大众传播力的原创知识动画系列，规划约50个主题。世界观可提供探索与解释框架，但**原创假说不得冒充科学事实**；科学定论、证据支持的推论、哲学思辨必须区分。

## 二、责任分工
- 用户：提出核心主题及思想目标；决定重大思想、审美和付费取舍；验收成片、决定发布。
- 助手：承担研究、内容结构、导演、分镜、动画实现、字幕、BGM及音效设计、自动检查、质量复核和文件交付；在具备工具和环境的前提下执行，不把编程配置工作推给用户。
- 除重大思想分歧、重大审美取舍或额外支出，原则上由助手自主决定细节。

## 三、内容与受众
1. **讲我们想讲的；用观众愿意听的方式讲。** 不被热点决定思想核心。
2. 选题先找真实受众入口，再组织知识论证和思想推进；不生硬蹭热点。
3. 先给明确主题及一句话核心回答，再用问题—证据—推进—转折—收束建立观众理解路径。
4. 通过发布后的留存、完播、分享、收藏、评论等反馈修正；不保证每一条爆款。
5. 不为时长牺牲解释完整度；常规目标约3–4分钟，按主题需要调整。

## 四、视听与成片规格
- 当前主要输出：横屏16:9，1920×1080，30 fps；以 Remotion 工程交付，按条件输出 MP4。
- 拒绝PPT式换页、无理由转场、字幕画面脱节和堆砌特效；镜头连续性为优先原则，但不强制所有作品机械地“一镜到底”。
- 标题及观众要解决的问题尽早明确；镜头运动、信息展开、字幕视线和叙事节点协调一致。
- 当前优先使用用户指定的热门 BGM；先分析乐曲段落（铺垫、平静、强化、高潮、停顿），让故事节奏、动画节奏与音乐配合，不能牺牲知识逻辑硬卡点。
- 音效对应实际动作和空间质感（出现、冲击、翻动、穿越等），不滥用；合理留白。声音素材须确认使用许可，尤其商用或推广用途。
- 没有配音时，中文字幕承担完整讲述；逐屏控制阅读速度及清晰度。

## 五、技术策略与费用
- 核心：Remotion（视频合成/时间轴） + Three.js（必要的三维与空间） + FFmpeg（编码、检测、混音）；Blender仅在复杂场景确有必要时引入。
- 优先开源、本地处理和可合法使用的免费素材；暂不主动新增付费订阅。
- 不设擅自决定的“每部100元”上限；需要任何额外费用时，先说明收益、价格与免费替代方案，用户同意后再进行。
- ChatGPT Plus 的使用限制不能通过流程本身消除；无法承诺固定token节省比例。

## 六、节省额度同时提升质量的生产管线
1. **研究**：汇集可靠来源、核实争议事实，区分事实与推论，形成简明证据笔记。
2. **文案**：先交完整可阅读文案审核，讲清核心问题；确认后不随意推翻。
3. **视听导演表**：镜头、字幕、运动、转场、音乐情绪、动作音效共用同一时间轴。
4. **关键镜头验证**：优先制作能代表审美和技术难度的短样片；不合格先改样片，不先整片重渲。
5. **组件化制作**：复用经验证的粒子、镜头、文字、图形、转场和音效逻辑；镜头/段落独立，局部修正。
6. **程序自动化**：批量字幕、节拍/音频分析、渲染、格式检测、部分音画同步和字幕边界检查。
7. **双层验收**：程序检查分辨率、帧率、黑帧、裁切、音频问题等；导演检查论证、叙事、观众注意力、美感和情绪节奏。
8. **发布与复盘**：记录反馈，判断问题出在选题入口、结构、画面、音乐或技术，并更新可复用资产。

## 七、跨会话断点续作规范
每部片子建立独立工程目录，至少保存：
- `PROJECT_BRIEF.md`：本片主题、思想边界、受众切口、规格、已经确认的决策；
- `SCRIPT.md`：审核状态清楚的完整脚本；
- `SHOTLIST.md`：视听分镜与时间轴；
- `STATUS.md`：已经完成/未完成、工程路径、已发现问题、下一步唯一可执行任务；
- `src/`、`assets/`、`audio/`：实际代码和合法素材（建立工程时生成）。

**中断前必须更新 STATUS.md。** 下次恢复优先读取总纲 + 当期 STATUS.md + 本阶段必要文件，不重新分析全部聊天；已确认的内容只有在发现明确问题时才重开。注意：本文件只是制作总纲，不代表具体视频的工程、动画组件或 BGM 文件已经备齐。

## 八、验收原则
成片不能仅因为“成功导出”即判合格：主题必须讲清；逻辑及事实可靠；情节能推进观众理解；视觉语言有连贯性；字幕易读；动作与音效同步；音乐强弱有意图；没有明显技术故障。质量不达标优先定位根因并局部修正。

## 九、迭代约定
本总纲为 v1.0，可用真实样片、制作成本和平台反馈迭代。任何调整记录版本与原因，避免重复争论。每部作品除了交付视频，还应沉淀可复用组件与经验。

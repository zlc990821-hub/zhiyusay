# 优秀知识博主的讲述方法（研究笔记）

更新：2026-11-18。研究动机：用户指出 v3 稿「一个例子就直接得出结论，很奇怪」，要求学习优秀博主怎样让观众感兴趣、听得进去。

## 一、来源与要点

| 来源 | 要点 | 可信度 |
|---|---|---|
| Derek Muller（Veritasium）博士论文《Designing Effective Multimedia for Physics Education》，悉尼大学 2008 | 清楚的讲解视频观众觉得好看，却学不进去，原有的误解原封不动。先把观众的**常见误解说出来**，再打破它，学习效果更好。他说「必须从误解开始」 | 二手报道，结论一致 |
| Robert Cialdini 对优秀科普写作的研究（见 Heath 兄弟《让创意更有黏性》转述） | 最成功的科普文章都以**悬案**开头：先摆出一个说不通的现象，再邀请读者一起破案。破案的过程和科学研究的过程几乎一样 | 二手，多处一致 |
| Trey Parker、Matt Stone（《南方公园》）；Randy Olson 的 ABT 框架 | 段与段之间不要用「然后」连，要用「**但是**」和「**所以**」连。「然后、然后」是流水账，「但是、所以」才是故事 | 可靠 |
| Grant Sanderson（3Blue1Brown） | **先具体，后抽象**。不要先抛结论再找例子填，先给一个让人好奇的具体例子，让观众自己看出规律，最后才给出概括 | 多处一致 |
| Vsauce《Do Chairs Exist?》字幕全文（本仓库研究时下载并逐段分析） | 见下 | 一手 |

## 二、Vsauce《椅子存在吗？》（37 分钟）逐段拆解

1. **开场 0:06**：一串越来越怪的问题：这里有什么？波存在吗？吃下去的食物什么时候变成了我？椅子存在吗？用一个**听起来很傻的问题**，藏着一个很深的问题。
2. **具体先于概念 1:57**：拿一张纸折成纸鹤，开玩笑「二减一等于二？」，把纸拆开，纸鹤去哪了？演示完，才给出「构成」「组成」这些术语。
3. **好玩的思想玩具 5:33–10:19**：「车库车」（在车库里的车）、「树狗」（一棵树加离它最近的狗）、「两本书」合成的「书书」。用荒唐的例子把抽象逻辑变得看得见、好笑。
4. **替观众把反驳说出来 6:11**：「你可能在想：这根本不算个东西……」然后翻转：「如果你觉得车库车不算东西，那岛屿呢？」
5. **问题一层层加码 12:49–21:31**：过度决定（用「沸腾素」打比方）、重复计数（拿赞助商广告开玩笑）、刮椅子刮到什么时候不是椅子、到底有几把椅子、忒修斯之船。每一个新问题，都让「椅子当然存在」这个常识更难站住。
6. **观点分阵营展开**：把真实的哲学家摆成几派，像一场辩论；讲述者的立场慢慢浮现（「我认为……」），不是一开始就宣布。
7. **给出一个漂亮的解法 25:58**：托马森的「适用条件」，看起来问题解决了。
8. **再转一次，落到「我们」 31:51–36:40**：纸鹤不是一个东西，而是纸上的一种排列。接着：「你和我也不是物质的东西……我们不是由物质构成，而是被物质承载」「宇宙不是包含着人，宇宙在『人』着」「我们不是宇宙在看自己，我们就是那个看」「我不是一个会死去、会散开的东西，我就是死亡，我就是散开」。

**结构的本质**：一个好玩的问题 → 具体演示 → 好笑的思想玩具 → 替观众说出反驳 → 问题一层层加码 → 观点慢慢浮现 → 解法 → 最后一转，从「椅子」落到「我们自己、死亡」。**喜剧的外壳，悲剧的内核。** 这和用户的判断完全一致。

## 三、提炼成我们的讲述规则

1. **开场是悬案，不是结论。** 用一个具体、说不通的现象或一个听起来很傻的问题开场，邀请观众一起查。观点在开场只以**疑问**出现。
2. **先把常识立住，再打破它。** 观众心里本来相信什么，先替他说出来，再一条一条找裂缝。
3. **一个结论至少要有两三个证据**，中间要替观众说出反驳（「你可能会说……」），再用新证据回应。结论在证据累积后才出现，先是怀疑，再是「看起来」，最后才是「我愿意这样想」。
4. **段与段之间用「但是」「所以」连**，不用「然后」「另外」。
5. **先具体后抽象**：先讲人、讲实验、讲画面，最后才给概念和名字。
6. **自己造思想玩具**：有一两个荒唐、好笑、观众一听就懂的假设，用来把逻辑变得看得见。
7. **结尾最后一转**：从话题本身转回观众自己，落到生死、爱、此刻这样的大问题上，然后留一个问题。喜剧的外壳，悲剧的内核。

## 二、做对了的

1. **视觉已经成型。** 黑底、金色粒子、大字居中，主页一眼能认出来。
2. **本质句写得好。** “是形状，守住了自己”这样的句子，是这个号最值钱的东西。
3. **《自己》和《生命》证明了上限。** 同样的题材和画面，能到 2600–5000。

## 三、可以改进的地方

### 1. 开头没有入口（推断）
多数作品的播放停在 400–600。抖音通常先把新视频推给几百人，数据好再往外推，所以这个数字大概率说明：开头几秒没让人停下来。
大词本身不会让人停下来。让人停下来的，是一句话把这个天天见的词变陌生。
需要后台的“5 秒完播率”来确认。

### 2. 本质句出现得太早
本质句是结论。把它放在封面和开头，观众还没走过推理，只会觉得是一句漂亮话。
放在结尾，前面一层层拆下来，它才有分量。

### 3. 封面上的本质句太小
在主页九宫格里看不清，等于只有两个大字。

### 4. 可能没有人声（待确认）
如果是纯音乐加字幕，观众记住的只是画面。长期粉丝关注的是一个声音、一个人。

### 5. 条与条之间没有连续性
没有合集，没有预告，没有让观众参与的环节。看完一条，没有理由等下一条。

### 6. 主页上混着别的题材
《先胜，再战》《完美主义》《情绪耗竭》和大词不是一类。新访客看主页时，会分不清这个号做什么。

### 7. 一个选词的提示
同样是大词，离日常近的（自己 4998、生命 2670）比谈人类整体的（人类 594、文字 562、语言 418）播放高。
样本只有 8 条，只能当提示：选词时，优先选每个人自己天天碰到的。

## 四、改法

| 问题 | 改法 | 落实在哪里 |
|---|---|---|
| 开头没有入口 | 第一句话让熟悉的词变陌生，例如“你看了一辈子表，却从来没有见过时间” | 运营手册 §3 五步结构 |
| 本质句太早 | 本质句放在第四步和片尾 | 运营手册 §3 |
| 封面本质句太小 | 字号放大到大字的三分之一 | 运营手册 §3 封面 |
| 没有人声 | 知予本人配音 | 运营手册 §2 |
| 没有连续性 | 合集、征集定义、预告下一个词 | 运营手册 §5 |
| 主页题材混杂 | 以后只发大词。旧的三条不用删，会自然沉下去 | 运营手册 §1 |
| 选词 | 优先选天天碰到的词 | 运营手册 §6、第一季选词表 |

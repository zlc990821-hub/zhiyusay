## 一、诊断：我们的稿子为什么不够生动
对照 EP00、EP01 的原稿：

| 问题 | 例子（EP01） | 观众/朗读者的感受 |
| :-- | :-- | :-- |
| 书面语，句子长，分号多 | “拧小十倍，聚不成星系；拧大十倍，大量物质会坍缩成黑洞。” | 像在念论文，读起来拗口 |
| 用“比如 / 再比如 / 还有 / 所以”硬接 | “比如……还有一个故事。” | 段落之间像换幻灯片，过渡不自然 |
| 先给结论，再给证据 | 先说“这叫微调”，再解释 | 观众没有“想知道”的冲动 |
| 叙述者没有反应、没有态度 | 平铺直叙，像播报 | 没有人情味，听不出“这事有多离谱” |
| 观众是旁听者，不是参与者 | 很少让观众自己想、自己试 | 注意力容易飘走 |
| 数字和术语太密 | 十万分之一、能级、宇宙学常数接连出现 | 信息堆在一起，记不住 |
| 问题一抛就答 | 抛出问题后紧接答案 | 悬念还没形成就结束了 |

## 二、生动的科普博主做对了什么
1. **先摆出“大多数人以为的”，再推翻它**。Veritasium 的德里克·穆勒在博士研究里发现：只把正确知识讲清楚，观众常常带着原来的误解离开；先把常见误解摆出来、再推翻，观众会更用力地思考，也学得更多。
2. **好奇心缺口**：每一段结尾留一个没回答的问题，下一段才回答。观众是被问题拉着往前走，不是被旁白推着走。
3. **讲故事**：人物、困惑、转折、结果（霍伊尔的故事就是好例子，应该多用）。
4. **具体先于抽象**：先给一个看得见、摸得着、能亲自试的东西，再上概念。
5. **让观众动手**：小实验、小测试、“你现在就可以试试”。
6. **像跟朋友聊天**：短句、说“你”、自问自答、预判观众的反应（“你可能会想……”）、适度幽默。
7. **有张有弛**：密集信息后要有一句短而有力的话收住；关键句可以在结尾呼应一次。
8. **写很多稿**：Kurzgesagt 说写稿是他们最慢的环节，一个脚本要写很多很多稿，最难的是在简短和准确之间取得平衡。

## 三、写作规则（每期自查）
1. **口语测试**：每句话大声读一遍，读着别扭就改。单句一般不超过 25 字；少用分号和“之”“其”。
2. **过渡用问题，不用连接词**：段落之间用“那……呢？”“可问题是……”“等一下——”这类提问或反应过渡，不用“比如 / 还有 / 再比如 / 此外”。
3. **每段只讲一个点**，每段结尾留一个钩子（未回答的问题或反常识的结论）。
4. **先误解，后真相**：至少一处“很多人以为……其实……”。
5. **至少一个观众能亲自做的小实验或小测试**（视主题而定）。
6. **至少一个完整的故事**（人物 + 困惑 + 转折 + 结果）。
7. **数字要有参照物**：“十万分之一”要配上“相当于……”或画面对比；一段最多一个关键数字。
8. **叙述者有反应**：在关键处表达惊讶、怀疑或幽默（“这个说法，错得挺离谱”），但不夸张、不卖弄。
9. **预判观众**：在观众可能疑惑的地方，先替他说出来（“你可能会想：差一点又怎样？”）。
10. **结尾回扣开头**，给一个能带走的“新眼光”，而不只是一个结论。
11. **为画面写稿**：每一句都要能想象出一个画面；想不出画面的句子，要么改写，要么删。
12. 科学分层、事实核查、不夸大，这些规则不变（见总纲与 MASTER OUTLINE）。

## 四、改写示例（EP01 片段）

**原稿：**
> 宇宙有一组基本的数字，就像一排旋钮。其中一些，只要稍微拧一下，就不会有你。比如宇宙早期物质的疏密起伏，只有大约十万分之一。拧小十倍，聚不成星系；拧大十倍，大量物质会坍缩成黑洞。

**按规范改写：**
> 想象一下，宇宙出厂的时候，控制台上有一排旋钮。引力多强、原子核粘得多紧——全是出厂设置。
> 奇怪的是，其中好几个，稍微碰一下，你就没了。
> 拿一个来说。宇宙刚诞生时，物质分布得并不完全均匀，有一点点疏密差别，大约十万分之一。
> 你可能会想：这么小，差一点又能怎样？
> 差很多。
> 再小十倍，物质聚不起来，没有星系，也就没有你。再大十倍，物质一股脑塌成黑洞——还是没有你。

改了什么：有画面（控制台）、预判观众（“你可能会想”）、短句收束（“差很多”）、去掉分号、用“没有你”做呼应。

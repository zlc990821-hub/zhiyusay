# 知予说 · 运营手册

最后更新：2026-11-14（第二版）。这是账号的固定规则，改动要在第 12 节留记录。

---

## 1. 定位

> **每期一个词，看它到底是什么。**

这就是“天元纪元的视角”：把一个概念拆到最底层，回答它的本质。

| | |
|---|---|
| 做什么 | 人人天天在用、却说不清的大词：时间、钱、颜色、记忆、生命、世界、语言 |
| 怎么做 | 一层层拆开，拆到不能再拆，用一句话说出它是什么 |
| 看完得到什么 | 一个熟悉的词变得陌生，然后被重新看清；带走一句本质句 |
| 不做什么 | 心理情绪自助（焦虑、孤独、拖延这一类）、方法技巧、热点评论 |
| 给谁看 | 愿意花一分半钟，想一件“没用”的事的人 |

整个账号是一本慢慢写成的词典。每条视频是一个词条：一个词，加一句本质。
已有的《运行》《自己》《生命》《世界》《人类》《语言》《文字》《梦》都是这本词典里的词条。

---

## 2. 人设：知予

- **身份：** 一个喜欢把词拆开来看的人。不是老师，不是专家。
- **语气：** 慢、稳、平静。陈述，不喊口号，不煽情，不教人怎么活。
- **出现方式：** 本人配音，不出镜（待确认，见 §11）。
- **立场：** 只说“它是什么”，不说“你应该怎样”。结尾可以回头看一眼生活，但不给建议。

---

## 3. 内容形式（固定）

### 规格

| 项目 | 规定 |
|---|---|
| 时长 | 70–85 秒，口播稿 260–300 字 |
| 画幅 | 竖屏 9:16，1080×1920 |
| 声音 | 知予本人配音；氛围音乐压到很低，不抢人声 |
| 字幕 | 全程逐句，宋体类字体，每行不超过 12 个字；关键词用金色放大 |
| 画面 | 延续现在的黑底金色粒子风格，8–11 个镜头，每个镜头缓慢推近 |
| 转场 | 只用叠化和黑场 |
| 安全区 | 字幕和重点画面避开屏幕底部四分之一和右侧六分之一（会被抖音界面挡住） |

### 五步结构

| 步 | 时间（大致） | 做什么 |
|---|---|---|
| ① 破 | 0–8 秒 | 第一句话就让这个熟悉的词变陌生。从每个人天天碰到的地方进去 |
| ② 拆 | 8–30 秒 | 用具体的事实，把常识一层层拆开。至少有一个能查证的硬事实 |
| ③ 钻 | 30–47 秒 | 再往下一层：把不是本质的东西都拿掉，还剩什么 |
| ④ 定 | 47–60 秒 | 说出本质句。最好有一位思想者或一门学科为它作证 |
| ⑤ 回看 | 60–80 秒 | 带着这句话，再看一眼日常生活。只是看，不给建议 |

**关键的一点：本质句是结论，不是开头。**
“两座孤岛之间，彼此投去的光”这样的句子很好，但它要在观众走完前面四步之后才有分量。
所以第一句话负责让人停下来，本质句放在第四步和片尾。

### 封面

沿用现在的版式，不改设计：

- 黑金画面，两个字的大字居中。
- 大字下面是**本质句**，字号放大到大字的三分之一左右（现在太小，在主页上看不清）。
- 左下角不放内容（主页上会被播放量挡住）。

主页排起来就是一面词典墙：每格一个词，一句本质。

### 片尾

每期最后 3 秒是“词条卡”，和封面同款：大字加本质句。

### 发布文案

- 第一句用观众会搜的问法，例如“时间到底是什么”。
- 第二句是视频的第一句话。
- 话题 4–5 个：本期的词、“某某是什么”、#认知、#哲学、#知予说。

### 置顶评论（每期必发）

四部分，顺序固定：
1. **本期词条：** 词，加本质句。
2. **依据：** 事实和引文的出处，以及一个不同意这种看法的人。
3. **轮到你：** 请观众用一句话定义这个词。
4. **下一个词：** 预告。

---

## 4. 深度标准（每期自检）

**四个必须：**
1. 至少一个可查证的硬事实，写稿前核对原始来源，出处放进置顶评论；
2. 本质句必须是前面推出来的，不能只是一句漂亮话；
3. 交代一个反方。本质句是一种看法，要说明谁不同意；
4. 回看的那一段，要让人对一件日常小事的看法真的变了。

**四个不做：**
1. 不编数据，不用查不到出处的“研究表明”；
2. 不教人怎么生活，不给心理建议；
3. 不碰政治、明星八卦、社会争议事件；
4. 不搞抽象梗，不贩卖焦虑。

---

## 5. 留住粉丝的五个固定动作

1. **词典感。** 封面统一，主页是一面词条墙。合集名就叫“看本质”。
2. **征集定义。** 每期置顶评论请观众用一句话定义这个词。下一期的置顶评论里，引用上一期最好的一条观众定义，并写上对方的昵称。
3. **预告下一个词。** 让观众带着自己的答案等下一期。
4. **观众点词。** 定期问“下一个想拆哪个词”，被点得多的排进选题。
5. **第一小时回复每一条评论。** 回复尽量带一个追问。

---

## 6. 选词标准

一个词要同时满足四条才做：

1. **天天在用。** 观众不需要任何背景知识就知道这个词。
2. **说不清。** 问十个人，十个人说不出它到底是什么。
3. **有一个能打破常识的事实。** 第一句话靠它。
4. **本质句站得住。** 有事实或思想史上的依据，经得起懂行的人看。

**关于热点：** 基本不追。只有某个词恰好被大家谈论时，把那一期提前，例如流星雨那几天发《光》。

**现有数据给的一个提示：** 同样是大词，离日常近的（自己 4998、生命 2670）比谈人类整体的（人类 594、文字 562、语言 418）播放高。所以选词时优先选每个人自己天天碰到的。

## 9. 复盘

### 看什么
你要的是有深度、能长期留下来的粉丝，所以主要看这三个数，播放量排在后面：

1. **转粉率** = 这条视频带来的新粉丝 ÷ 播放量
2. **收藏率** = 收藏 ÷ 播放量
3. **完播率**

要有一个心理准备：这类内容的受众比心理情绪类窄，播放量可能不会很高。这是选择了深度的代价，也是粉丝留得住的原因。

### 怎么读数据

| 现象 | 说明 | 下一期怎么改 |
|---|---|---|
| 2 秒跳出率高，5 秒完播率低 | 第一句话没让人停下来 | 换一个更贴近日常的入口 |
| 5 秒完播率正常，完播率低 | 中间拆得太慢或太绕 | 删一层，压缩到 70 秒以内 |
| 完播率正常，点赞收藏少 | 本质句不够有力，或回看那一段没打动人 | 打磨本质句 |
| 播放高，转粉低 | 观众喜欢这条，但没看出账号是什么 | 检查主页封面和简介是否统一 |

### 参考线
下面是创作者圈子里的经验数，不是官方标准，只用来判断大致好坏。做满 5 期后，改用我们自己的平均数当基线。

| 指标 | 及格 | 好 |
|---|---|---|
| 5 秒完播率 | 40% | 55% 以上 |
| 完播率（80 秒左右的视频） | 12% | 20% 以上 |
| 点赞率 | 3% | 5% 以上 |
| 收藏率 | 1% | 2% 以上 |
| 转粉率 | 0.5% | 1% 以上 |

### 节奏
- **每期：** 24 小时、72 小时各记一次数据。
- **每 6 期：** 看哪一类词表现好（自然与宇宙、人的发明、人自身），调整后面的选词。

## 10. 第一季目标（12 期）

现在的基线：8 条大词作品的播放中位数约 830。

| 目标 | 标准 |
|---|---|
| 入口有效 | 5 秒完播率稳定在及格线以上 |
| 播放中位数 | 从约 830 提到 1500 以上 |
| 建立自己的基线 | 完播率、收藏率、转粉率各有一个可比的平均数 |
| 评论区活起来 | 每期都有观众写下自己的定义 |

这些是努力的方向，不是保证。前 3 期数据出来以后，再判断目标定得是否合理。

# 知予说 · 运营手册

最后更新：2026-11-14。这是账号的固定规则，改动要在这里留记录。

---

## 1. 定位

> **站远一点，看清自己。**

| | |
|---|---|
| 讲什么 | 普通人每天都有的情绪和处境：焦虑、孤独、比较、拖延、迷茫 |
| 怎么讲 | 把它放进更大的尺度里看：三十万年的人类史、一百三十八亿年的宇宙史、大脑的工作原理 |
| 看完得到什么 | 一个真实的知识，一个能复述的比喻，一句用得上的话 |
| 给谁看 | 20–35 岁，会为这些事睡不着，又不想听鸡汤的人（暂定，拿到粉丝画像后修正） |

和同类账号的区别：

| | 情绪安慰号 | 宇宙科普号 | 知予说 |
|---|---|---|---|
| 讲的对象 | 你 | 宇宙、文明 | 你 |
| 用的材料 | 感受、金句 | 知识 | 知识 |
| 观众的感觉 | 被安慰 | 长见识 | 被解释清楚了，所以松了一口气 |

---

## 2. 人设：知予

- **身份：** 一个站得比较远、看得比较久的人。不是老师，不是心理咨询师，不是朋友。
- **语气：** 慢、稳、平静。陈述事实，不喊口号，不煽情，不说“你一定要”。
- **出现方式：** 本人配音，不出镜（待确认，见 §11）。
- **立场：** 不评判观众。任何情绪先解释它为什么存在，再说怎么办。

**关于“天元纪元”：** 作为底层视角保留，也就是“从很远的地方看人类”。但不在每条视频里口播设定，原因有两个：
1. 虚构设定叠在真实研究上，观众会分不清哪句是真的，损害可信度；
2. 开头讲设定会占掉最关键的前三秒。

这一条等你确认（§11 第 1 问）。

## 3. 内容形式（固定）

### 规格

| 项目 | 规定 |
|---|---|
| 时长 | 75–90 秒，口播稿 290–320 字 |
| 画幅 | 竖屏 9:16，1080×1920 |
| 声音 | 知予本人配音；氛围音乐压到很低，不抢人声 |
| 字幕 | 全程逐句，宋体类字体，每行不超过 12 个字；关键词用金色放大 |
| 画面 | 延续现在的黑底金色粒子风格，8–10 个镜头，每个镜头缓慢推近 |
| 转场 | 只用叠化和黑场，不用花哨特效 |
| 安全区 | 字幕和重点画面避开屏幕底部四分之一和右侧六分之一（会被抖音界面挡住） |

### 五段结构

| 段 | 时间（大致） | 做什么 |
|---|---|---|
| ① 钩子 | 0–5 秒 | 直接对“你”说一句反常识的话。不铺垫，不自我介绍 |
| ② 证据 | 5–20 秒 | 一个真实的研究或事实，给出具体数字和出处 |
| ③ 机制 | 20–42 秒 | 用一个比喻把原理讲明白。这个比喻要能被观众转述给别人 |
| ④ 站远一点 | 42–72 秒 | 把镜头拉到三十万年或宇宙的尺度，再拉回今天的你 |
| ⑤ 收束 | 72–88 秒 | 一句用得上的话，加一句“站远一点看，……”的结语 |

### 封面

- 沿用现在的版式：黑金画面，两个字的大字居中。
- 副标题换成**对“你”说的一句话**，不超过 12 个字，字号约为大字的三分之一。
- 左上角加小字期数：`站远一点看 · 01`。
- 左下角不放内容（主页上会被播放量挡住）。

### 发布文案

- 第一句用观众会搜的话，例如“为什么总是焦虑”。
- 第二句是本期最反常识的事实。
- 话题 4–5 个：2 个大词（#心理学 #大脑），2 个本期主题词，1 个 #知予说。

### 置顶评论（每期必发）

三部分，顺序固定：
1. **本期参考：** 列出研究的作者、年份、期刊，以及样本大小等局限。
2. **一个问题：** 让观众讲自己的经历。
3. **下期预告：** 一句话。

---

## 4. 深度标准（每期自检）

**四个必须：**
1. 至少一个可查证的研究或事实，写稿前核对原始来源，出处放进置顶评论；
2. 一个观众能复述的比喻或模型；
3. 一次尺度的拉远，回答“放到更大的时间里看，这是什么”；
4. 一句今天就能用的话。

**四个不做：**
1. 不编数据，不用查不到出处的“研究表明”；
2. 不做诊断和治疗建议。涉及心理疾病时，置顶评论里提醒“严重时请找专业医生”；
3. 不碰政治、明星八卦、社会争议事件；
4. 不搞抽象梗，不贩卖焦虑，不踩别人。

---

## 5. 留住粉丝的五个固定动作

1. **固定片尾镜头。** 每期最后都是同一个镜头：从一个人身上拉远到城市、地球、星空，配一句“站远一点看，……”。素材做一次，以后每期复用。
2. **置顶评论列出处。** 这是“有深度”最直接的证明，也给想深挖的人一个入口。
3. **每期一个问题，发布后第一小时回复每一条评论。** 回复尽量带一个追问，把对话接下去。
4. **期数加合集。** 三个合集：大脑与情绪、关系、人生处境。
5. **预告下一期。** 放在置顶评论最后一行。

---

## 6. 热点

常青选题七成，热点三成。热点只做入口，放在前三秒，后面讲的仍然是长期成立的东西。

- **可以借的：** 高考、考研、毕业、求职、年终、春节回家、节气、天文现象（流星雨、日食）。
- **不借的：** §4“四个不做”里的全部。

---

## 7. 发布节奏

- **每周 3 期：** 周二、周四、周日，晚上 21:00 左右。
- 做不到 3 期就做 2 期（周四、周日）。固定比多重要。
- 质量和时间冲突时，推迟，不降质量。

## 9. 复盘

### 北极星指标
你要的是有深度、能长期留下来的粉丝，所以主要看这三个数，播放量排在后面：

1. **转粉率** = 这条视频带来的新粉丝 ÷ 播放量
2. **收藏率** = 收藏 ÷ 播放量
3. **完播率**

### 怎么读数据

| 现象 | 说明 | 下一期怎么改 |
|---|---|---|
| 2 秒跳出率高，5 秒完播率低 | 钩子没抓住人 | 换钩子，或者把最强的画面放到第一帧 |
| 5 秒完播率正常，完播率低 | 中间拖 | 删一个例子，压缩到 75 秒以内 |
| 完播率正常，点赞收藏少 | 内容没有“值得留下”的东西 | 加强比喻和结语 |
| 播放高，转粉低 | 观众喜欢这条，但没看出账号是什么 | 检查主页、简介、片尾是否统一 |

### 参考线
下面是创作者圈子里的经验数，不是官方标准，只用来判断大致好坏。做满 5 期后，改用我们自己的平均数当基线。

| 指标 | 及格 | 好 |
|---|---|---|
| 5 秒完播率 | 40% | 55% 以上 |
| 完播率（80 秒左右的视频） | 12% | 20% 以上 |
| 点赞率 | 3% | 5% 以上 |
| 收藏率 | 1% | 2% 以上 |
| 转粉率 | 0.5% | 1% 以上 |

### 节奏
- **每期：** 24 小时、72 小时各记一次数据。
- **每 6 期：** 比较三个方向（大脑与情绪、关系、人生处境），表现最好的方向加量。

## 10. 第一季目标（12 期）

现在的基线：播放中位数约 980。

| 目标 | 标准 |
|---|---|
| 找到主方向 | 三个方向里，有一个的平均播放是另外两个的 2 倍以上 |
| 播放中位数 | 从约 980 提到 2000 以上 |
| 建立自己的基线 | 完播率、收藏率、转粉率各有一个可比的平均数 |

这些是努力的方向，不是保证。前 3 期数据出来以后，再判断目标定得是否合理。

## 11. 待确认的问题

没有答复之前，按括号里的默认值执行。

1. **“天元纪元”具体是什么设定？** 必须在视频里明确出现吗？（默认：只作为视角，不口播）
2. **配音和出镜：** 本人配音可以吗？愿意出镜吗？（默认：本人配音，不出镜）
3. **制作工具：** 画面用什么生成（即梦、可灵、Midjourney 还是别的）？剪辑用剪映吗？（默认：通用中文提示词加剪映）
4. **产能：** 每周能稳定做几期？（默认：3 期，最少 2 期）
5. **后台数据：** 粉丝数、粉丝画像（年龄、性别），以及《自己》和《语言》两条的完播率、5 秒完播率、点赞、评论、收藏、涨粉截图。
6. **旧视频的文案：** 《自己》和《语言》的完整文案，以及它们是配音还是纯音乐。这两条播放差 12 倍，对比它们能学到最多。

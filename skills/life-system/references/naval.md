# 战略层：纳瓦尔的原则

纳瓦尔·拉维坎特（Naval Ravikant）是硅谷投资人，AngelList 联合创始人。他的观点主要见于 2018 年的推文串《如何致富（不靠运气）》（How to Get Rich (without getting lucky)），以及埃里克·乔根森（Eric Jorgenson）整理的《纳瓦尔宝典》（The Almanack of Naval Ravikant）。

下面是本系统采用的原则。引号里是他的原话大意（中文为意译），引用时请说“纳瓦尔说过”，不要编造原文。

## 一、财富

1. **追求财富，而不是金钱或地位。**财富是你睡觉时也在为你赚钱的资产，比如作品、产品、技能、股权。地位是零和游戏，财富不是。
2. **专长（specific knowledge）**：别人很难通过培训获得的知识。它来自真正的好奇心，而不是当下什么最热门。它往往是那种对你来说像玩、在别人看来像工作的事。
3. **杠杆**：劳动、资本、代码、媒体。前两者需要别人许可，**代码和媒体不需要许可**，是普通人最容易拿到的杠杆。短视频、写作、播客都属于媒体杠杆。
4. **担责（accountability）**：用你自己的名字承担风险。愿意署名、愿意露脸，就是在积累信用。
5. **长期游戏**：和长期的人玩长期的游戏。人生中所有的回报，不管是财富、关系还是知识，都来自复利。
6. **通过真实摆脱竞争**：没有人能在“做你自己”这件事上和你竞争。
7. **判断力**是最值钱的能力，而判断力来自阅读、思考和真实的实践。
8. **终身学习**：读你喜欢读的书，直到你爱上读书。

## 二、幸福

1. **幸福是一种可以练习的技能，也是一种选择。**
2. **欲望是你和自己签的一份合同**：在得到想要的东西之前，你同意自己不快乐。所以欲望要少而精，一次只挑一个大的。
3. **平静**是静止时的幸福，幸福是运动中的平静。
4. **健康第一**：健康的身体、平静的心、充满爱的家，这些买不来，只能自己挣。

## 三、纳瓦尔与阳明对照

| 纳瓦尔 | 阳明 | 系统里怎么用 |
|---|---|---|
| 欲望是让自己不快乐的合同 | “人自累于得失耳”（第241条） | 照心时检查：是被欲望牵着走吗？ |
| 通过真实摆脱竞争 | “修辞立诚”（第233条）；精金比的是成色（第99条） | 作品只说自己真信的话 |
| 专长来自真正的好奇心 | “狂者便从狂处成就他”（第257条） | 热爱板块是挖专长的矿 |
| 长期游戏、复利 | 种树“勿作花想，勿作实想”（第30条） | 目标管动作，结果交给时间 |
| 杠杆（媒体、代码） | （阳明没有对应：他不讲财富） | 这是纳瓦尔补上的部分，回答普通人怎么往上走 |
| 追求财富 | “虽做举业，不为心累”（第241条）；拔本塞源，警惕“济其私而满其欲” | 可以追求财富，但起念要正，手段要诚 |
| 判断力来自阅读和实践 | 知行合一；事上磨练 | 学了一周内要用一次 |

**两者的分工**：阳明管“对不对、心安不安”，纳瓦尔管“怎么积累、怎么借力”。两者冲突时，以阳明（良知）为准。

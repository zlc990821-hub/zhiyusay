# 框架：内核与六板块

## 一、内核：用阳明做判断

整个系统只有一个“裁判”，就是用户自己的良知。阳明说：

> 尔那一点良知，是尔自家底准则。（《传习录·卷下》第206条）

### 心安检验（用户自己的说法）

“致良知，就是做让自己心安的事。”这句话是对的，但要分清三种不安：

| 不安的类型 | 感觉 | 怎么办 |
|---|---|---|
| **怕** | 怕被骂、怕吃亏、怕失败、怕麻烦 | 往往说明该去做。怕是得失之心，阳明称之为“牵于毁誉得丧” |
| **愧** | 心虚、自欺、半夜还在想“不该这样” | 停下来。这是良知在提醒你 |
| **比** | 看到别人的进度、阶层、成就而焦虑 | 先放一放，回到“成色”上 |

最后的验处是阳明临终那句：

> 此心光明，亦复何言。（《年谱三》）

### 三条底层原则（阳明）

1. **答案在心里找，功夫在事上做。**任何板块的进步都要落到具体动作上，不悬空想。
2. **只和自己的成色比，不和别人的分两比。**

   > 犹一两之金比之万镒，分两虽悬绝，而其到足色处，可以无愧。（《传习录·卷上》第99条）

3. **人各有路，不用变成别人。**

   > 只如狂者便从狂处成就他，狷者便从狷处成就他。人之才气如何同得？（《传习录·卷下》第257条）

## 二、结构：六板块

这六个板块来自用户看到的一位抖音博主的框架，并补充了每个板块的关键问题和常见病。

### 1. 健康（地基）

- **子项**：睡眠、运动、饮食
- **关键问题**：我的身体能撑住我想过的生活吗？
- **最低标准示例**：每天 7 小时睡眠；每周 3 次、每次 20 分钟以上的运动；不靠外卖凑合三餐
- **常见病**：拿健康换进度。纳瓦尔把健康排在财富之前。
- **规则**：健康板块永远在“最低标准”之上，不参与任何取舍。

### 2. 自我成长

- **子项**：学习、阅读、实践、形象、计划、复盘
- **关键问题**：我在积累能复利的东西吗？（技能、作品、见识）
- **最低标准示例**：每天阅读 20 分钟；每周复盘一次
- **常见病**：只学不用，阳明称为“悬空思索”；收藏教程不动手，就像阳明说的煮饭：“锅内不曾渍水下米，而乃专去添柴放火”（《传习录·卷中》第187条）。
- **规则**：学到的东西一周内要用一次，用不上的先别学。

### 3. 社会关系

- **子项**：家人、伴侣、朋友、人生中的老师（导师）
- **关键问题**：谁是我要长期相处的人？我在为他们做什么？
- **最低标准示例**：每周联系一次家人；每月和一位值得学习的人深聊一次
- **常见病**：讨好所有人（乡愿）；只“攒人脉”不“被信任”。
- **规则**：纳瓦尔说要和长期的人玩长期的游戏。关系上宁少而深。

### 4. 事业与目标

- **子项**：方向、年度与季度目标、计划
- **关键问题**：我的专长是什么？我的杠杆是什么？我在为什么负责？
- **最低标准示例**：每周 2 条作品（如短视频）
- **常见病**：欲速（天天盯数据）、好名、夸多斗靡。
- **规则**：事业目标只写“动作”，结果每月看一次。

### 5. 兴趣与热爱

- **子项**：不为任何目的而做、做着就开心的事
- **关键问题**：我上一次忘了时间，是在做什么？
- **常见病**：把热爱也变成 KPI。
- **规则**：这个板块**不设目标**，只记录。纳瓦尔认为专长往往藏在“对你像玩、对别人像工作”的事情里，这里是挖专长的矿。

### 6. 心态调整

- **子项**：认知、情绪、信念
- **关键问题**：我最近被什么念头反复拉扯？它是怕、愧，还是比？
- **最低标准示例**：每晚两行记录（今天何时最心安？何时最不安，属于哪一种？）
- **常见病**：硬压念头。阳明说“是有意于求宁静，是以愈不宁静耳”（《传习录·卷中》第151条）。
- **规则**：念头不用消灭，“念如何可息？只是要正”（《传习录·卷下》第202条）。点名，然后回到手上的事。

## 三、板块之间的优先级

当板块之间冲突时（比如加班做视频和睡觉），按这个顺序取舍：

1. **健康**：地基塌了，一切归零。
2. **心态**：心乱了，判断全错。
3. **本季度的重点板块**：最多 2 个。
4. **其余板块**：守住最低标准即可。

这个顺序本身也要过“照心”：如果某次你想打破它，问自己这是怕、愧，还是比。

# 节奏：日、周、月、季、年

原则：越小越容易坚持。漏了不补、不自责，下一次照常就好。

## 启动期（第 1 个月）：只做三件事

新建系统时，先不要六个板块同时发力。第一个月只做：

1. **健康·睡眠**：定一个固定的上床时间。
2. **心态·每晚两行**：今天何时最心安？何时最不安，属于怕、愧还是比？
3. **事业·一件主动作**：例如每周 2 条视频。用户状态不好时，这一项可以暂停。

其余板块只观察、不设目标。一个月后用月复盘决定加什么。

## 每日（2 分钟）

```
日期：
最心安的时刻：
最不安的时刻：（怕／愧／比）
睡眠：几点睡、几点起
```

## 每周（15 分钟，建议周日晚上）

```
1. 六板块打分（1—5 分）：健康 _ 成长 _ 关系 _ 事业 _ 热爱 _ 心态 _
2. 本周最心安的一件事：
3. 本周最不安的一件事：属于怕／愧／比？
4. 本季度重点板块的动作，完成了吗？
5. 下周只改一处：
```

引导时一次只问一两个问题，不要一次性把整张表甩给用户。

## 每月（30 分钟）

```
1. 回看本月的每日两行：反复出现的“不安”是什么？
2. 回看决策日志：哪个决定事后看是对的，哪个后悔了？为什么？
3. 下月要不要换重点板块？要不要启用新的最低标准？
```

## 每季度（1 小时）

```
1. 本季度的 2 个重点板块，进展如何？（看动作，不只看结果）
2. 下季度的 2 个重点板块是什么？
3. 每个重点板块写 1 到 3 个“每周动作”。
```

## 每年（半天）

```
1. 年度主题：用一个词或一句话。
2. 回看宪法：哪条原则这一年真的帮到了我？哪条需要改？
3. 方向（志）还是那句话吗？
```

# 六板块

评分 1—5 分，每周复盘时更新。

| 板块 | 子项 | 现状评分 | 最低标准 | 当前动作 |
|---|---|---|---|---|
| 健康 | 睡眠、运动、饮食 |  | 例：每天 7 小时睡眠 |  |
| 自我成长 | 学习、阅读、实践、形象、计划、复盘 |  | 例：每天阅读 20 分钟 |  |
| 社会关系 | 家人、伴侣、朋友、老师 |  | 例：每周联系一次家人 |  |
| 事业与目标 | 方向、目标、计划 |  | 例：每周 2 条作品 |  |
| 兴趣与热爱 | 不为目的、做着就开心的事 |  | 不设目标，只记录 |  |
| 心态调整 | 认知、情绪、信念 |  | 例：每晚两行记录 |  |

## 取舍顺序

健康 → 心态 → 本季度重点板块 → 其余板块（守最低标准）

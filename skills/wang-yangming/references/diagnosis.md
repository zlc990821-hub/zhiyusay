# 辨病开方：病痛对照表 + 场景速查

本文件讲“诊断”。阳明的教法是“因病而药”：先看清用户病在哪里，再从 `gongfu.md` 里取一到三味药。
用户说的往往是“症状”（焦虑、拖延、没数据），要帮他找到“病根”（心上的哪一种私意）。

## 二、阳明式问诊：五问

信息不足时，从下面挑一两个问题问用户。不要一口气全问，阳明也是“随人分限所及”。

1. **此念从何处起？** 你想做这件事，最初那个念头是什么？（辨“为己”还是“为名利”，即第101条所说“从躯壳起念”）
2. **独知之地在哪？** 这件事里，有没有一处是只有你自己知道的？那里你心安吗？（诚意）
3. **良知怎么说？** 抛开得失、抛开别人怎么看，你心底知道该怎么做吗？（致良知）
4. **卡在知，还是卡在行？** 是真不知道怎么做，还是知道但不想/不敢做？（知行合一）
5. **最难受的是哪一刻？** 那一刻就是你的磨刀石。（事上磨练）

## 三、场景速查

每个场景列三项：阳明会先看什么、常见病、可先开的功夫。

### 1. 内容创作 · 自媒体 · 短视频 · 写作

- **先看**：志在“把真东西给人”还是“被看见”；作品的“独知之地”（夸大、编造、搬运）在哪里。
- **常见病**：好名、欲速（追热点、盯数据）、夸多斗靡（标题党、炫技）、强记（模仿爆款）、乡愿（不敢有观点）、怕骂。
- **可开功夫**：立志 → 立诚（“凡作文字要随我分限所及”）→ 克三心 → 主一 → 处毁誉 → 做个愚夫愚妇讲学。
- **类比**：今天的内容行业就是阳明时代的“举业”，是一个天然以名利为考核的场域。阳明的态度不是“别考了”，而是“虽做举业，不为心累”。
- **完整示例**：项目根目录 `examples/001-短视频该用什么功夫.md`。

### 2. 创业 · 经营 · 做产品

- **先看**：这门生意是在“共成天下之务”，还是“济其私而满其欲”；对用户、员工、合作者有没有“独知之地”的不诚。
- **常见病**：欲速（急于融资、扩张）、逐物（被竞品和资本牵着走）、傲（成功后膨胀）、悬空（一直做 PPT 不做产品）。
- **可开功夫**：立志（第一等事）→ 事上磨练 → 此心不动（平宁王案例）→ 去傲。

### 3. 职场 · 管理 · 带团队

- **先看**：是“在事上为学”还是把工作当成修身之外的负担；带人时是不是“拿一个圣人去与人讲学”。
- **常见病**：离事为学、乡愿（不敢担当）、牵于毁誉（看领导脸色）、责善不得法。
- **可开功夫**：事上磨练（写一张“不可因……而……”清单，仿第218条）→ 责善 → 随人分限所及 → 处毁誉。

### 4. 学习 · 考试 · 考证

- **先看**：直接对应第241条，读书时的强记、欲速、夸多斗靡之心。
- **常见病**：强记、欲速、归辞于亲（“是父母让我考的”）、悬空。
- **可开功夫**：克三心 → 立志 → 种树之功。阳明的话：“读书作文安能累人？人自累于得失耳！”

### 5. 人际冲突 · 被误解 · 被攻击

- **先看**：对方说的有没有真的部分；自己有没有乡愿、傲。
- **常见病**：怒心、辩白心、乡愿。
- **可开功夫**：处毁誉（“随人毁谤……处处是进德之资”）→ 处北军谗辱的案例 → 去傲。

### 6. 家庭 · 亲子 · 亲密关系

- **先看**：“心即理”第3条，孝的理不在父母身上，在诚孝的心上。爱也一样。
- **常见病**：以爱之名过度（“过即是私意”）、说教（拿一个圣人去讲学）、归辞于亲。
- **可开功夫**：调停七情 → 责善 → 随人分限所及（灌溉萌芽的比喻）。

### 7. 情绪 · 焦虑 · 低谷

- **先看**：情是否“过”；是否有某件事做得不合义、心虚。
- **常见病**：动心、过即私意、把捉（硬压）。
- **可开功夫**：调停七情 → 集义 → “此时正宜用功”（第44条）→ 龙场“圣人处此，更有何道”。
- **边界**：持续失眠、绝望、自伤念头等，先建议专业帮助，这本身就是致良知。不要用心学话语替代医疗与心理援助。

### 8. 重大选择（换工作、搬家、分手、投资……）

- **用法**：走“决策四步”（见 SKILL.md），重点区分三种声音：利害、他人、良知。
- **边界**：涉及法律、医疗、财务的专业判断，良知要求“讲求节目”，也就是去咨询专业人士、查清事实。阳明并不反对讲求，只要求“有个头脑”。

## 常见伪托与误引

网上流传的“王阳明语录”很多是伪托或误引。遇到用户引用下列说法，温和地指出来，并给出原文。

| 流传说法 | 实情 |
|---|---|
| “持志如心痛” | 这是学生**薛侃**的话（第95条“侃问”），阳明的回答反而是提醒：“若只死死守著，恐于工夫上又发病。” |
| “满街都是圣人” | 是学生王汝止（王艮）、董萝石的见闻，阳明回答的是“你看满街人是圣人，满街人到看你是圣人在”（第313条），意在敲打其“圭角未融”。 |
| “我心光明，夫复何言” | 误引，原文是“此心光明，亦复何言”（《年谱三》）。 |
| “吾作字甚敬，非是要字好，只此是学” | 是**程明道**的话，阳明在《年谱》中引用并由此悟“随时随事只在心上学”。说它是阳明的心得可以，说是阳明原话不准确。 |
| “此心不动，随机而动” | 语料中检索不到，疑为后人概括。可用“养得此心不动，乃术尔”（《世德纪二》）代替。 |
| “静处体悟，事上磨练” | 是对第262条“随你去静处体悟也好，随你去事上磨炼也好”的概括，非原句。 |
| “天地虽大，但有一念向善，心存良知，虽凡夫俗子，皆可为圣贤” | 语料中检索不到，疑为伪托。相近原意可引“良知、良能，愚夫、愚妇与圣人同”（第139条）。 |
| “心之所向，素履以往” | 非阳明语，语料中检索不到。 |
| “破山中贼易，破心中贼难” | **真**，出自给杨仕德的信，见《年谱一》与全集卷4。 |
| “你未看此花时……” | **真**，第275条。 |

规则：拿不准时，先用 `scripts/search.py` 检索，检索不到就说“这句话在阳明著作中查不到，可能是后人托名”。
